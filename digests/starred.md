# 我的收藏清單

看到每日精選裡有興趣的 repo，在下面加一行 `owner/repo`（跟 GitHub 網址上的格式一樣，例如 `mizorewww/laya-mlx`），存檔後就會被下個月的收藏彙整頁抓到。

**兩種加收藏的方式：**

1. 直接跟 Claude 說「收藏 owner/repo」，請它幫你加進來並 commit。
2. 書籤這個直接編輯連結，點開就能編輯存檔（不用自己找檔案）：
   https://github.com/Kao-web-TW/github-tech-digest/edit/master/digests/starred.md

一行一個，不確定格式對不對也沒關係，格式錯誤的行會被自動忽略，不會壞掉。
